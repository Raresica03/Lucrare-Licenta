# Full-Stack Project: React TypeScript + .NET 8 + SQL Server for Unirum

This project consists of a **React TypeScript** frontend, a **.NET 8 Web API** backend, and an **SQL Server database**.

GIT repository: https://github.com/Raresica03/Lucrare-Licenta

### **1. Prerequisites**
Before setting up the project, ensure you have the following installed:
- **Node.js (LTS version)** - [Download](https://nodejs.org/)
- **.NET SDK 8** - [Download](https://dotnet.microsoft.com/en-us/download)
- **SQL Server** - [Download](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)
- **SQL Server Management Studio (SSMS)** - [Download](https://aka.ms/ssmsfullsetup)
- **Git** (optional but recommended) - [Download](https://git-scm.com/)

---

## **📂 Frontend: React + TypeScript**
```sh
cd frontend/reactjs
npm install
npm start
```

## **📂 Backend: .NET 8**
```sh
Start the application in your editor
```
## **📂 Database: Microsoft SQL**
```sh
Open SSMS and login with the windows credentials and servername localhost
Right click the database folder and click import
Import the BAK file from the git repository
```
